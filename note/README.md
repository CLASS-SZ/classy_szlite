# Cluster counts from maps: a note

A write-up of the cluster-count work documented at
https://class-sz.github.io/classy_szlite/clusters/, in MNRAS format: [main.pdf](main.pdf).

Build it with `latexmk -pdf main.tex` (needs the MNRAS class, `mnras.cls` and `mnras.bst`, from a TeX
distribution). The figures in `figures/` come from `docs/clusters/make_figures.py`.
